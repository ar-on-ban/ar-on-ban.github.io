Overview

gb-gws is a personal OAuth client application used solely by Aron Banyasz to access his own Google Workspace data. This is not a public service.

  • Storage: OAuth tokens are stored locally on the account owner's own machine.

Limited Use Disclosure: gb-gws's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
